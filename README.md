# Kalkulator smeše

Besplatan kalkulator smeše za svinje, živinu, goveda i ovce. Izračuna koliko kilograma žitarica, proteinskog dela i premiksa ide u šaržu (Pirsonov kvadrat), proveri energiju i esencijalne aminokiseline (lizin, metionin+cistin, treonin, triptofan) i pokaže cenu smeše.

Sajt: https://smesa.rs/

Ceo kalkulator je jedan fajl, `index.html` (HTML, CSS i JavaScript, bez servera). Recepture se čuvaju u pregledaču korisnika.

Vrednosti hraniva i preporuke su orijentacione. Za konkretnu smešu važe deklaracija premiksa, analiza zrna i savet stručnjaka.
